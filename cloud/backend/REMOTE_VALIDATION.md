## 协议故障测试

`tests/test_remote.py` 通过真实 ASGI 路由和原任务监督子进程验证协议，MuJoCo 模块使用人工替身；网络故障由测试传输层注入。这 13 项与上表真实 MuJoCo 进程验证分开记录：

- 默认关闭，浏览器 JWT 不能冒用执行端凭据。
- 离线拒绝且不保存排队任务；远程独占时本地入口拒绝新任务。
- 重复领取、最终应答丢失不二次启动；启动许可应答丢失时保守失败，启动次数为零。
- 网络中断仍在本地完成，恢复后交付同一任务；主动关闭时取消，离线结果留下回执以便补传。
- 并发提交只接收一个；冲突执行端 session 拒绝；错误任务凭据拒绝；延迟报告不会倒退阶段。
- 缺 checkpoint 不能报成功；超长／不完整／哈希错误的录像拒绝；文件未归档不开放完成结果；重复确认幂等。
- 尚未启动的交接超时或主动断开后不重放；需人工复核的状态会传回服务端并继续阻止任务。

## 协议回归与历史完整环境复现参考

协议回归不需要真实仿真。后面的真实 MuJoCo 与浏览器步骤仅适用于已经取得兼容外置执行实现和资产使用授权的完整环境；先按 [REMOTE.md](REMOTE.md) 准备私有配置。自动进程验证前停止手动运行的执行端；脚本会建立新数据目录、启动自己持有的本机服务端和执行端，用 TCP 代理注入故障，最后停止自己创建的进程。只克隆本公开仓库不能完成这些真实执行步骤。

```bash
# 仓库根目录：协议回归，不需要真实仿真或机器人。
bash cloud/backend/test.sh -q --tb=short
bash apps/web/run.sh test:run

# 显式运行真实 MuJoCo：两进程、断网补传、取消、主动关闭。
cd cloud/backend
env -u PYTHONPATH -u PYTHONHOME .venv/bin/python -m scripts.validate_remote
```

脚本的脱敏报告、进程日志与原任务文件写入 `.local/remote-validation/run-*/`，保留用于核查；不会输出密码、令牌或执行端密钥。两端业务进程不共享数据目录；验证脚本会读取两边的日志来核对启动次数和结果。

另在仓库根目录启动两个手动演示终端后，可运行已有浏览器检查：

```bash
WEB_QA_ORIGIN=http://127.0.0.1:8010 \
WEB_QA_ENV_FILE=.local/remote-demo/server.env \
WEB_QA_ACCOUNT=judge WEB_QA_RUN_SIM=1 \
node apps/web/tests/e2e/live-smoke.mjs
```

Node 与浏览器工具准备见 [网页验证说明](../../apps/web/VALIDATION.md)。浏览器脚本读取私有配置登录，只提交仿真。测试结束在执行端 Ctrl+C，保持远程执行关闭。

## 当前边界

已经验证的是同一 Ubuntu 上两个独立角色通过 loopback HTTP 通信，并实际切断 TCP 连接。跨电脑／公网链路、真实 HTTPS 部署、长时间网络故障、断电与磁盘损坏恢复仍未实测。协议可补传已有持久记录，不承诺持久目录丢失后的自动恢复。

没有创建华为云资源、OBS 存储或使用云产品；没有开通／调用华为视觉模型，没有执行机器人硬件。远程执行限固定仿真路线，所有实机控制仍默认关闭。华为云账号、区域、费用和部署验证留待实际授权后完成。
