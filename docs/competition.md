# 官方要求与当前公开进度

核对日期：2026-10-19。以[第十一届华为 ICT 大赛中国创新赛官方页面](https://e.huawei.com/cn/talent/#/ict/innovation-details?zoneCode=027425&compId=85132021&type=C002&zoneId=98269700)赛题 1 为准；页面公开数据接口 `compId=85132021`、`zoneId=98269700`、`numberVersion=89`。正式提交前仍需复核阶段通知。

本对照以初赛最低材料为主，并单列决赛后续要求。不估算完成百分比；“未核验”不等于用户一定没有完成。

| 官方要求／阶段 | 当前证据 | 剩余事项 |
| --- | --- | --- |
| 赛题 1 使用华为云码道 CodeArts 代码智能体 | 已实际用于分析、审查和文档主笔，[真实贡献](codearts-evidence.md) | 不能把其他工具完成的业务代码、测试、部署记为 CodeArts 产出 |
| 利用已有智能体／Skills 关联创建 RDS、Redis 等华为云服务并快速部署 | 配置及流程研究；无已创建服务／云部署证据 | 后续需按官方要求完成实际关联、部署和可核实记录；RDS／Redis 是列举，不推断必须全开，也不宣称 ECS 单项一定足够 |
| 华为云部署与可视化 Demo | 有本地应用与本次 GitHub Pages 静态展示 | GitHub 静态托管不等于华为云业务部署，也不提供在线任务 |
| 初赛：模板 1 作品信息收集表 Word；其他材料可选附上 | 已有源码、历史结果、目标与限制说明 | 正式 Word 是否填写、报名资格／状态及是否提交，本仓库未核验 |
| 中国总决赛：模板 2 答辩 PPT、可视化 Demo 地址、实现代码、相关数据与复现说明、开源截图 | 公开应用子集、静态地址和相关说明 | PPT 与正式材料未核验；完整实现、资产获取授权、完整公开复现与华为云 Demo 尚有缺口 |
| 中国及全球总决赛开源 | 本仓库已公开许可清楚的子集 | 旧导航／机器人资产／权重未公开，不能称完整比赛作品已开源 |
| 全球总决赛后续 | 以前述材料为基础 | 根据通知补充应用落地进展等材料 |

官网页面公布报名至 2026-11-30，初赛 2026 年 12 月，中国总决赛 2027 年 3 月、全球总决赛 2027 年 5 月；具体材料截止日期与资格按官方通知核验。官方知识产权及作品传播展示条款需由团队阅读完整文本。

初赛页面评分为创新性 60%、应用价值 40%；不是本仓库自评成绩。当前仅有有限场景的仿真量化结果，实机、真实照片问答、落地价值与云服务部署仍需各自证据。开源和固定展示地址使材料更可查看，不自动消除这些缺口。
