# 仿真评测公开材料

**本目录不是可独立运行的仿真发行版。** 旧导航／仿真运行源码、Go2 XML／OBJ、策略权重暂缓公开；不能通过本目录启动 MuJoCo。见 [公开范围](../../../docs/RELEASE_SCOPE.md)。

本次分发：人工预设 `routes.json`、原创批测入口 `evaluate.py`、原创绘图工具 `plot_evaluation.py`、`evaluation.json`，以及 `validation/` 历史配置、轨迹和统计。评测入口仍需要未分发的执行实现；脚本公开不代表依赖完整。

历史最终结果为侧箱 15/15、错位短墙 12/15 并 3 次碰撞；较差 0.4 m/s 候选 4/15 仍保留。完整说明及图片见 [展示与评测来源](../../../docs/demo.md)。历史记录来自原私有开发环境，不是本公开副本的新仿真运行。

应用 API 与网页在没有仿真环境时仍能运行，默认报告仿真未配置，并明确拒绝执行；见 [公开应用运行说明](../../../docs/PUBLIC_APPLICATION.md)。未来扩大分发需先确认源码组件许可、模型获取条件和资产再分发条件。
